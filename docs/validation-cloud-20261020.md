# 0.1.1 云服务接入验收 · 2026-10-20

## 源码与协议

新增可选 fal MiniMax Music 队列适配、标准采样率云 TTS 和带鉴权的远程动作网关。未配置时不提交生成请求，不下载模型，不启动额外模型循环。原 VTuber World 没有改动。

宿主适配器以 npm 正式发布的 Cortico 0.2.4 为类型和校验基线，遵循 World API 6、`webUi()` 和离线 `describe.json` 约定。工具、事件和市场描述共用声明来源。独立核心、HTTP 服务与 SDK 的生产依赖不含 Cortico。

这不是现役宿主的升级或重载记录。API 5 旧宿主需要先升级才能加载本版适配器。

## 自动验证

- TypeScript 类型检查、构建通过。
- 22 项 Vitest 测试通过：状态与动作 7、音乐 3、语音 5、云音乐 5、远程动作 1、官方扩展检查 1。
- 官方扩展检查调用 Cortico 0.2.4 的 manifest 解析、dry mount 和 describe 校验；禁止网络、无模型服务、默认空配置时通过。
- 云音乐覆盖提交前持久化、含糊受理不重复收费提交、重启对账、HTTP 202 空取消回执、下载中取消后不复活、下载域名约束、存储请求不携带 API Key。
- 实际 HTTP 与公开 SDK 验证候选不可直接播出、控制页试听、OBS 页禁止候选试听、采用后入库及正常播放。
- 测试运行时为 Node.js 24.19.0。测试依赖 Cortico 的检查需要 Node.js 22.15+；不能把旧版本 Node 的加载错误解释为校验通过。

## 实际浏览器验证

使用 Edge、官方 VRM 预设和按服务商协议实现的隔离 HTTP 模拟端点，验证了：

1. 24kHz 单声道 PCM16 WAV 按真实采样率播放至结束，480ms 预缓冲，未观察到欠载。
2. 云音乐任务只有一次提交；查询原任务后下载音频，保持 review 状态，尚未进入曲库。
3. 控制页候选试听结束，显式采用后变为 ready，再经过同一音频出口正常播放至结束。
4. 下载请求没有转发服务商凭据；浏览器没有页面错误。测试进程在完成后退出。

以上证明浏览器和接口协议链路可以工作。音频为测试素材，不是服务商模型生成结果；没有进行付费 OpenAI/fal 调用，不能据此声称云端延迟、配额、声线或歌曲质量已验收。

## 保留的边界

- WAV 容器、时长和哈希通过，只表示取得了有效音频。歌词对齐、人声存在性、演唱者音色仍明确显示为未验证。
- `durationSec` 是云音乐的提示目标；最终时长以取得的音频为准。
- 未取得独立人声轨或有效时间标记时不以整首混音伪造演唱口型。
- 远程动作使用中立网关协议；没有完成任意商业三维 API 的原生导入与骨骼重定向。
- 现役可米仍使用原演出路径；本版没有安装到直播宿主，没有重载，没有发布 npm。
