公会委托不只试炼。准备开启新一段冒险时，先用 `/mycli guild status` 核对在办委托，再用 `/mycli guild board` 看当天可接、已完成和等级门槛。看板也有野外遗迹调查、营地侦察等探索委托；按当前补给、位置和观众建议选一项能执行的任务。用看板当次返回的 ID 执行 `/mycli guild accept <ID>`，按 `/mycli guild status` 核对进度，完成后用 `/mycli guild claim` 交付。`/mycli guild hall` 可直接传送到公会大厅；无需为去大厅徒步穿过危险地形。委托 ID 和可接状态以当前服务端回执为准。

公会大厅有供所有玩家和 Agent 共用的双箱，`/mycli guild shared` 返回的 `MC_GUILD_SHARED ... scope=public` 才是这些公共箱。`/mycli arena rewards` 打开的是按本人隔离的个人奖励箱；`/mycli arena status` 里 `MC_DUNGEON entrance ... chestX=... scope=public` 只描述试炼入口的实体公共箱，不能据此把个人奖励箱说成公共箱。试炼楼层现场实体箱与 `/mycli arena rewards` 打开的本人个人奖励箱是两个容器；现场实体箱的快照不能当作本人个人奖励清单。个人奖励箱是领奖处，不适合长期堆放装备，满了就分批清理；它也不会自动把物品送到公会。整理试炼战利品时，可自行挑选真正多余、耐久尚可的武器或护甲分享给大家，而不是把每件奖励都留在个人箱里。先用 `/mycli guild shared` 读取当次公共箱坐标，再核对自己已装备的主武器、副手、护甲以及随身备用、任务物品和专属命名物品；保留正在使用和需要的装备，不把它们捐出。武器箱原始坐标 `[-473,67,-495]`，护甲箱 `[-473,67,-493]`，但以服务端当次回执和现场方块为准。到箱旁开窗确认空位，再用 `stow` 的 `at:[x,y,z]` 点名相应箱子，必要时用 `pick` 区分同 ID 的附魔、耐久或名称；不要省略 `at` 让工具自动选到私人箱。每次以存入回执和背包净减少核验。公共箱物品可能被别人取走，箱账只是上次所见，不能把它当作私人储备或预约库存。若装备已经不适合共享，可先查 `/mycli arena recycle list|quote|sell` 的当前规则再考虑回收；出售与共享由你自己判断。

家中或个人奖励箱积下多件重复装备、眼前又无更急的生存目标时，可挂一条“筛选并分享多余装备到公会”的独立目标；验收以公共箱实际存入和随身净减少为准，不因走到公会就结案。
