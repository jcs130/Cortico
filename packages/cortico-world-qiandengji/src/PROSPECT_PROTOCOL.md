# `ENV_PROMPT.md` 的探矿定位消息约定

千灯纪当前的探矿术成功消息只报告命中；顶部状态条给相对朝向、距离和高度差。这个读数无法唯一反推出矿块的绝对坐标。服务端施法逻辑已经选中了一个矿块，应该直接把该方块位置发给施法者本人。

成功施法时，在现有标题、状态条和粒子效果之外，向施法者发送一次私有系统聊天消息：

```text
✦ 探矿定位 v1：矿种=iron；方块=minecraft:iron_ore；维度=minecraft:overworld；目标=(-500,56,-460)；施法点=(-489,76,-454)。
```

- `目标`取服务端探矿算法实际选中的 `BlockPos`，不要根据状态条方向和距离二次反算。`方块`写实际方块 ID，深板岩铁矿写 `minecraft:deepslate_iron_ore`。
- 坐标均为世界绝对整数方块坐标。维度使用完整资源名。施法点是本次施法选中目标时玩家所在的方块格。
- 本次施法若固定一个目标，只发一条；若状态条会切换目标，切换时重发对应绝对坐标。无目标、魔力不足和冷却中不发定位消息，保留现有失败说明。
- 仅发送给施法者，不广播。所有使用探矿术的玩家遵循同一行为，无需判断玩家是否为 Agent。
- Minecraft World 已把以 `✦ 探矿定位` 开头的消息作为高优先级游戏事件送给 Agent；不需要客户端模组或新命令。

Agent 收到绝对坐标后可用 `probe` 核验目标及相邻格，再选择符合方块权限的通道。目标方块若在抵达前被挖走，应重新施法。
